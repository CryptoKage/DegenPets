## 3.4 Quant Lab: Strategy Experimentation

*   **Lategame Utility:** A premium feature unlocked with a significant $DGPT payment (250 $DGPT). (Can be bought up to **four** times)
*   **Functionality:** Allows a player to assign **one** owned Pet to the Quant. While assigned, the player can select *any* of the 12 core strategy types (EMA Cross, MACD, etc.) for that pet to use, overriding its native NFT strategy. Players gain access to more parameters beyond the default settings by feeding to the algo (See Forge).
*   **Mechanism:** This strategy swap is an off-chain, in-game effect only active while the pet is assigned a Quant. Removing the pet from the quant slot reverts it immediately to its NFT-defined strategy and parameters.
