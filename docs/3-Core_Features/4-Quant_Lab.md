## 3.4 Quant Lab: Strategy Experimentation

*   **Lategame Utility:** A premium feature unlocked with a significant $DGPT payment (1000* $DGPT, high % burn* - target 90%*). This is an account-wide unlock.
*   **Functionality:** Allows a player to assign **one** owned Pet to the Lab. While assigned, the player can select *any* of the 12 core strategy types (EMA Cross, MACD, etc.) for that pet to use, overriding its native NFT strategy. The pet uses default parameters for the selected strategy while in the Lab.
*   **Mechanism:** This strategy swap is an off-chain, in-game effect only active while the pet is in the Quant Lab. Removing the pet from the Lab slot reverts it immediately to its NFT-defined strategy and parameters.
