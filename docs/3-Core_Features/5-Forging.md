## 3.5 Forging (f.k.a. Breeding): Evolution & Supply Sink

*   **Core Loop:** Players can select two owned Pet NFTs, pay a substantial Forging Fee (500* $DGPT, high % burn* - target 90%*), and permanently burn both parent NFTs.
*   **Offspring:** A new Pet NFT is minted. It inherits the Species/Strategy of the parent with the higher historical Win Rate (minimum 50* trades required; if neither qualifies, player chooses* or defaults* - TBD). Parameters are randomly generated for the inherited species, with a small chance* (e.g., 10%*) per parameter to directly inherit the value from the chosen parent. Offspring generation count is tracked on-chain.
*   **Verifiable Randomness:** Offspring parameter randomization utilizes Chainlink VRF for provably fair and tamper-proof outcomes.
*   **Purpose:** Acts as a major NFT supply sink, a significant $DGPT burn mechanism, and allows players to strategically refine their collection towards desired strategies over multiple generations.
